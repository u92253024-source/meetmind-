# 教務會議資料庫搜尋系統（MeetMind）

國立政治大學教務處 — 教務會議紀錄結構化檢索系統

以純前端單一 HTML 檔案，提供 **92～114 學年度、102 場教務會議、983 筆提案**的關鍵字檢索，
每一筆結果都可回溯到原始會議紀錄 PDF 的**確切頁碼**。

---

## 一、專案定位

教務會議決議是教務處日常作業的法源依據，但過去 23 年的紀錄只以 98 份 PDF 散落存放。
承辦人要查「某項規定是哪一年、哪一場會議通過的」，只能逐份開啟 PDF 用 Ctrl+F 慢慢找。

本系統把這 98 份 PDF 的提案內容結構化成 983 筆可查詢資料（原為 999 筆，
2026-08-11 去除 95 學年度 16 筆重複紀錄），並保留**頁碼級溯源**，
讓每一個查詢結果都能被查核，而不是只給出一段無法驗證的 AI 回答。

## 三、快速開始

本系統**無需安裝、無需後端、無需編譯**。

### 方式 A：本機瀏覽（建議）

因為程式用 `fetch()` 讀取 `data.json`，直接雙擊 `index.html` 會被瀏覽器的
CORS 政策擋住（`file://` 協議無法 fetch）。請在專案資料夾啟動一個簡易伺服器：

```bash
python -m http.server 8000
```

然後開啟 <http://localhost:8000/index.html>

### 方式 B：部署到網頁空間

把整個資料夾上傳到任何靜態網頁空間（校內網頁空間、GitHub Pages、Netlify）即可。
無需設定資料庫或伺服器程式。

> ⚠️ PDF 資料夾共 177.4 MB，部署前請確認空間容量與流量限制。
> ⚠️ 上線前請先處理 `REPORT.md` 中列出的個資遮罩問題。

## 四、使用方式

| 操作 | 說明 |
|------|------|
| 關鍵字搜尋 | 輸入即時查詢，比對案由、內容、決議、單位、會議名稱 |
| 多關鍵字 | 用空白分隔，需**全部命中**，例 `學則 修正` |
| 完整詞組 | 用引號包起來，例 `"外語畢業標準"` |
| 排除關鍵字 | 關鍵字前加減號，例 `通識 -遠距` |
| 年度篩選 | 92～114 學年度下拉選單 |
| 類型篩選 | 新增／修訂／申請／報告／其他（由案由自動判斷） |
| 排序方式 | 依相關度（預設）／依年度時序；未輸入關鍵字時自動用時序 |
| 檢視全文 | 點擊表格中的「內容摘要」或「決議摘要」開啟彈窗 |
| 開啟原文 | 點擊「開啟檔案」在新視窗開啟該場會議的 PDF，頁碼欄位標示提案所在頁 |
| 關閉彈窗 | 點擊遮罩、按「關閉」或按 `Esc` |

時序排序依 **年度 → 學期 → 會議次別（臨時會排最後）→ 提案序號**；
相關度排序以案由 ×5、內容 ×3、決議 ×2、單位 ×1、會議 ×1 加權計分，
同分時退回時序排序，確保同一組查詢條件每次得到相同順序。

## 五、資料維護

新增一場會議紀錄的流程：

1. 將 PDF 放入 `pdf/` 資料夾
2. 在 `data.json` 陣列末端新增該場會議的提案物件（欄位定義見 `SPEC.md`）
3. `fileName` 必須與 `pdf/` 中的檔名**完全一致**（含大小寫與中文字元）
4. 重新整理頁面即生效，年度下拉選單會自動擴充

> 目前 `data.json` 為人工／半自動整理產出，尚無自動化抽取腳本納入版本管理。

## 六、技術規格摘要

- **前端**：原生 HTML + CSS + JavaScript（ES2020），零框架、零第三方套件
- **資料**：單一 JSON 檔，載入後在瀏覽器記憶體中完成全部篩選與排序
- **AI 助理**（`indextest.html`）：Microsoft Copilot Studio webchat，以 iframe 嵌入側欄，
  內建使用次數上限與冷卻機制
- **相容性**：需支援 `fetch`、`async/await`、可選串連（`?.`）、空值合併（`??`）的瀏覽器
  （Chrome/Edge 80+、Firefox 74+、Safari 13.1+）
- **RWD**：1100px 與 768px 兩段斷點，手機版 AI 側欄改為底部展開

完整規格請見 [SPEC.md](SPEC.md)。`data.json` 的產製方式（PDF → JSON 的 AI 抽取工具與流程）
說明於 [EXTRACTION.md](EXTRACTION.md)——這是另一個獨立的 React + Gemini AI 工具產出的，
本專案的 `index.html`／`indextest.html` 只負責讀取與搜尋，不做抽取。
